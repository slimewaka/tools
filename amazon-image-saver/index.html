Amazon画像保存

版

できること

Amazon の商品ページで押すと、その商品の画像（大きいサイズ）を 1.jpg、2.jpg、3.jpg… と順番に名前を付けて保存します。

登録（最初の1回だけ・パソコンの Chrome / Edge）

  1. ブックマークバーが出ていなければ Ctrl+Shift+B を押して出します。
  2. 下のオレンジのボタンを、マウスでつかんでブックマークバーまで引っぱって離します。これで登録完了です。
📷 Amazon画像保存
↑ ブックマークバーへ引っぱる
うまく引っぱれないとき
  1. を押します。
  2. ブックマークバーの空いているところを右クリック →「ページを追加…」。
  3. 名前に「Amazon画像保存」、URL の欄を消してから貼り付け（Ctrl+V）→「保存」。

使い方

  1. Amazon の商品ページを開きます。
  2. ブックマークバーの「Amazon画像保存」を押します。
  3. 見つかった枚数が出るので「OK」を押すと保存が始まります。
  4. 初回だけ「複数のファイルをダウンロードしようとしています」と出たら「許可」を押します。

・保存先はいつものダウンロードフォルダです。同じ名前のファイルがあると 1 (1).jpg のようになるので、商品ごとにフォルダを分けると分かりやすいです。
・色違いなどがある商品は、いま選んでいる色の画像が対象です。
・保存の前に、名前の頭に付ける文字（例: 靴_ → 靴_1.jpg）を入れることもできます。空のままなら番号だけです。
・スマホのブラウザでは使えません（パソコン向け）。
・新しい版が出たときは、古いブックマークを消して登録し直してください。
